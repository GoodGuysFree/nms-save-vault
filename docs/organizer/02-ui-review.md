# Owner review of the UI mockups

Mockups compared: `mockups/tk/` (D6) and `mockups/web/` (D7), side by side.

## Decision

**F1 = Tk** (D6). Some elements of the web version are better and are to be carried into
the Tk design.

## Per screen

| Screen | Owner's comment | Change to D6 |
|---|---|---|
| 01 Organizer | Prefers the web version's `>` expand marker over the two boxes at the left of each Tk row. Prefers the Tk version's vertical live lists on the right over the web version's horizontal slot tiles. | Replace the column-#0 platform boxes with a single `>` / `v` expand marker (platform stays visible in the Live column). Keep the vertical Steam / Xbox live lists. |
| 02 One save file expanded | The Tk version is right as it is. While one save file is expanded, the other lines should be de-emphasised (duller colours). | Add a muted row style for every line except the expanded one (and its versions) while a line is expanded. |

More comments to follow.
